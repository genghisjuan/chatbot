# Support Chatbot 🤖

An AI-powered support chatbot with cloud-based knowledge retrieval, built with FastAPI, Pinecone, and OpenAI.

## Features

- ✅ **Intelligent RAG** - Cloud-powered semantic search via Pinecone
- ✅ **Multi-format KB** - Upload PDFs to S3, auto-indexed
- ✅ **Real-time Analytics** - Track trending topics and user queries
- ✅ **Voice Support** - Speech-to-text input and text-to-speech output
- ✅ **Responsive UI** - Mobile-friendly interface with dark mode
- ✅ **Production-Ready** - Dockerized with PostgreSQL support

## Quick Start

### Prerequisites
- Python 3.11+
- OpenAI API key
- AWS S3 bucket (for KB storage)
- Pinecone account (for vector search)

### Installation

1. **Clone and navigate:**
   ```bash
   cd support_chatbot
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Set up environment variables:**
   - Copy `.env.example` to `.env`
   - Add your API keys

4. **Run the chatbot:**
   ```bash
   python -m uvicorn app.main:app --reload
   ```

5. **Access:** Open `http://localhost:8000/static/index.html`

## Configuration

See `.env.example` for all available settings. Key variables:

- `OPENAI_API_KEY` - Your OpenAI API key
- `DATABASE_URL` - PostgreSQL (Docker) or SQLite (local)
- `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` - For S3
- `PINECONE_API_KEY` - For vector search
